# Contributing

Thanks for your interest in Emotion Vision!

1. Fork the repo and create a branch: `git checkout -b feature/my-change`
2. Set up the environment: `python -m venv .venv`, activate it, then `pip install -r requirements.txt`
3. Make your change and run it with a webcam to check nothing broke
4. Keep the code readable. Follow the existing style and add comments where the logic isn't obvious
5. Commit with a clear message and open a pull request describing what changed and why

Please open an issue first for large changes. Include your OS, Python version and whether you used a GPU when reporting a bug.
